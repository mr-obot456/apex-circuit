# Apex Circuit

A 3D-inspired arcade racing game built with Python and Pygame Community Edition.
Dodge traffic, race through four stages, and beat your distance record.

## Requirements

- Python 3.9 or newer
- Pygame Community Edition (installed from `requirements.txt`)

## Run

```powershell
python -m pip install -r requirements.txt
python racing_game.py
```

## Controls

- **A / D** or **Left / Right**: steer
- **Down / S**: brake
- **Space / P**: start, pause, or resume
- **Esc**: quit

The game also supports pointer controls. Your best distance is saved locally in
your home directory.
